プライバシーポリシー

最終更新日: 2026年9月22日

合同会社Kパートナーズ(以下「当方」)は、Google スプレッドシート™ 用アドオン「電子印鑑スタンプ」(以下「本アドオン」)における情報の取り扱いを次のとおり定めます。

1. 要点

  • スプレッドシートの内容、印鑑に入力した名前・社名・日付、Google アカウントのメールアドレスを、当方のサーバーに送信・保存することはありません。
  • 印影の画像はお使いのブラウザの中で作られ、開いているスプレッドシートに直接埋め込まれます。
  • 当方のサーバーが受け取るのは、ライセンス確認のためのランダムな識別子だけです。

2. 本アドオンが求める権限と用途

権限(OAuth スコープ)用途
このアプリケーションがインストールされているスプレッドシートの表示と管理
spreadsheets.currentonly		開いているスプレッドシートの選択セルに印影画像を入れるため(必要に応じてそのセルの行の高さ・列の幅を広げ、中央揃えにします)、および承認欄(見出し・罫線・行の高さ・列の幅)を作成するために使用します。読み取るのは選択範囲の位置・結合の有無・列幅・行の高さと、承認欄の作成先が空かどうかだけで、セルに入力された値は取得しません。他のスプレッドシートやドライブ上のファイルにはアクセスできません。
Google アプリケーション内のプロンプトやサイドバーでのサードパーティ ウェブ コンテンツの表示と実行
script.container.ui		印鑑を作成するサイドバーとメニューを表示するために使用します。

3. 保存される情報と保存場所

Google のサーバー上(お客様の Google アカウントに紐づくアドオン用の保存領域)

  • ランダムに生成した利用者識別子(32桁の英数字。氏名やメールアドレスから作られたものではありません)
  • 最後に使った印鑑の設定、保存したプリセット(入力した文字を含みます)
  • お試し回数、Pro ライセンスの有効フラグ

これらは Google Apps Script の「ユーザー プロパティ」に保存され、当方は閲覧できません。アドオンをアンインストールすると利用できなくなります。

当方のライセンス確認サーバー

  • Pro を購入された方の利用者識別子と、対応する決済の識別子(Stripe の Checkout Session ID)

ライセンス確認の際、サイドバーから利用者識別子のみを送信します。アクセスログとして IP アドレス等を当方が収集することはありません(サーバーは Google Apps Script 上で動作しており、Google のインフラのログは Google の管理下にあります)。

4. 決済

Pro の決済は Stripe, Inc. の決済ページで行われます。カード情報は Stripe が取得・処理し、当方には渡されません。当方は決済の結果として、購入者のメールアドレス、氏名(入力された場合)、金額、日時、利用者識別子を Stripe の管理画面で確認でき、これらを領収書の発行、問い合わせ対応、法令上の帳簿保存のために利用します。Stripe による情報の取り扱いは Stripe のプライバシーポリシーをご確認ください。

5. 外部サービスへの通信

  • Google Fonts: 印影の書体を表示するため、サイドバーは Google Fonts からフォントを読み込みます。このとき、ブラウザから Google に IP アドレス等の通信情報が送られます。入力した文字の一覧が当方に送られることはありません。
  • ライセンス確認サーバー: 上記 3 のとおりです。

6. Google ユーザーデータの取り扱い(Limited Use)

本アドオンによる Google API から受け取った情報の使用および他のアプリへの転送は、Limited Use の要件を含む Google API Services User Data Policy に準拠します。本アドオンは Google ユーザーデータを、上記 2 に記載した機能の提供のためにのみ使用し、第三者への販売、広告目的での利用、AI・機械学習モデルの学習への利用、人による閲覧は行いません。

7. 第三者提供

法令に基づく場合を除き、当方が保有する情報を第三者に提供することはありません。

8. 情報の削除

アドオンをアンインストールすると、アドオンからのスプレッドシートへのアクセスは失われます。購入記録の削除や開示を希望される場合は、下記の窓口までご連絡ください。法令上保存が必要な帳簿類を除き、速やかに対応します。

9. 改定

本ポリシーを改定する場合は、このページで告知します。重要な変更は、アドオンのサイドバーまたはストアの掲載ページでもお知らせします。
